Where this is up to 02

ForgeCRA is in Phase 0 validation. It is not a live platform, and we are not going to pretend otherwise.

The only things on offer today are paid 90-day design-partner pilots for manufacturers, run by hand, and a free first cohort for suppliers. If the supply side doesn't want a neutral exchange, we would rather find that out now than build for a year first.

Binary analysis of firmware you already hold is a solved problem with good vendors serving it. ForgeCRA is not that. It solves the cross-company collection, quality-scoring and continuous attestation problem, which nobody owns.
